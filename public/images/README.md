# Images

All current files are self-authored placeholder SVG artwork (generated by
`node scripts/generate-placeholders.mjs`) meant to be replaced with real photography
before launch. See docs/IMAGES.md for dimensions, naming, compression, and alt-text
guidance, and docs/LAUNCH-CHECKLIST.md for the replacement list.

- brand/            Logos (keep filenames when replacing)
- jim/              Portrait + personal travel photos
- travel/           Homepage hero rotation
- destinations/     Destination gallery / backgrounds
- cardmaster/       App screenshots (1440x900, no personal data)
- success-stories/  One image per redemption story
- placeholders/     Spare artwork; safe to delete at launch
